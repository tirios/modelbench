1. Random fluctuations point in different directions on each reading, so combining many readings into one mean lets those deviations cancel and the estimate settles closer to the true value as the window grows.
2. A systematic offset pushes every single reading in the same direction by the same amount, so it appears identically in each term being combined.
3. Because that constant error does not cancel like random fluctuations do, the mean carries it forward unchanged no matter how many readings are pooled or how long the window becomes.
